# WAF Defensivo - Prevención de Robo de Identidad (México)
Proyecto certificado en LinkedIn - Licencias y certificaciones.

**Autor:** Giovani (@Giovani547) | **Stack:** Python FastAPI + Swift iOS

Este proyecto implementa un Web Application Firewall defensivo enfocado en proteger datos sensibles mexicanos (CURP/RFC) bajo lineamientos OWASP Top 10.

### -> Ver evidencia en LinkedIn: [Mi Certificación](https://https://www.linkedin.com/in/giovani-martinez-guzm%C3%A1n-a119a7315)

### Arquitectura Defensiva
- Detección: SQLi, XSS, Command Injection, Path Traversal
- Anti-Phishing: Homógrafos, typo-squatting, técnica del arroba (@)
- Cifrado: Fernet Python + iOS Keychain + FaceID
- Validación: Regex oficial CURP/RFC
- Logging seguro sin PII

### Disclaimer
Proyecto educativo y defensivo. No almacena ni procesa datos bancarios reales.
